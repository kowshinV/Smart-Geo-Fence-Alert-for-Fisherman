🛥️ Smart Geo-Fence Alert for Fishermen

A maritime safety assistant designed to protect fishermen from accidentally crossing international borders. This embedded system continuously monitors the boat’s GPS location and generates alerts when approaching restricted zones. It acts like a digital lighthouse guiding fishermen to safe waters.

🌊 Problem Statement
Unintentional boundary crossings can lead to:
* Arrest by foreign coast guards
* Fines and legal actions
* Loss of boats and resources
There is a need for a simple, real-time warning system to ensure safe and informed fishing.

🎯 Objectives
* Track boat location via GPS
* Compare coordinates with geo-fenced boundaries
* Give instant warnings through buzzer/SMS
* Improve situational awareness at sea

🔧 Technologies Used
* GPS Module
* Microcontroller (Arduino/NodeMCU/etc.)
* Alert System (Buzzer/GSM/Display)
* Embedded C / IoT Stack

✅ Features
* Real-time tracking
* Early danger alerts
* Portable and affordable
* Reduces border violations
